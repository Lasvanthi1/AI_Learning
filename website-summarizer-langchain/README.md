🚀 **Why am I learning LangChain?**

When I first started working with LLMs, I thought the process was simply:

**Send prompt → Get response**

But real-world AI applications are rarely that simple.

That's where **LangChain** becomes useful.

Instead of writing everything from scratch, LangChain helps connect different parts of an AI application into a structured workflow.

For example, my website summarizer follows this flow:

🌐 Website URL
↓
🕷️ Web Scraper
↓
📝 Prompt Template
↓
🤖 LLM (Groq + Llama)
↓
🔄 Output Parser
↓
💻 Gradio UI

### Some benefits I'm learning:

🔹 **Prompt templates** — create reusable prompts instead of hardcoding them.

🔹 **Chains** — connect multiple steps together into a clean pipeline.

🔹 **Model flexibility** — work with different LLM providers through a common interface.

🔹 **Output parsing** — convert model responses into formats that are easier for applications to use.

🔹 **RAG** — connect LLMs with external documents and knowledge bases.

🔹 **Agents & tools** — build applications where an LLM can decide which tools or actions to use.
